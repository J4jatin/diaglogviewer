What it does

DiagLogViewer is a PyQt5 desktop app for parsing and analyzing vehicle diagnostic logs. It handles AUTOSAR DLT format and Vector CANalyzer .asc files, decodes UDS service calls, automatically detects anomalies (log gaps, error bursts, OTA failures), and exports professional HTML reports.

Features

DLT Parser

AUTOSAR Diagnostic Log and Trace with UDS service ID decoding (15+ services)

CAN Bus Parser

Vector .asc format, OBD-II PID, J1939 PGN — with C++17 frame decoder

Anomaly Detection

Log gaps >500ms, error bursts, OTA failures, SecurityAccess violations

Performance Stats

Mean, P95, P99 inter-message gap. Per-ECU message rate breakdown

PyQt5 GUI

Dark theme, real-time filters, embedded matplotlib charts

HTML Reports

Jinja2-rendered diagnostic reports with anomaly tables and ECU stats

Quick Start

pip install PyQt5 matplotlib jinja2

# Optional: compile C++17 CAN frame parser
cd parser && g++ -O2 -std=c++17 -o can_frame_parser can_frame_parser.cpp

python main.py
